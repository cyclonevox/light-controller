# light-controller

用 Arduino Uno R4 WiFi 做的网页开关，控制一盏 12V 灯。手机连上以后打开板子自己的页面，点一下，继电器通断。没有 App，也不接云。

灯走独立的 12V 电源。板子只出控制信号，GPIO 不直接带灯。

## 接线

继电器模块（`S` / `+` / `-`）：

| 模块 | Uno |
|------|-----|
| `+` | `5V` |
| `-` | `GND` |
| `S` | `D8` |

灯那头（看螺丝旁的字，不要按颜色猜）：

- `COM` → 12V 电源正极
- `NO` → 灯正极
- 灯负极 → 12V 电源负极
- `NC` 不接

## 用法

1. 上电，手机连热点 `Light-Setup`，浏览器打开 http://192.168.4.1 ，填家里的 **2.4GHz** WiFi。
2. 板子重启连上后，点阵会滚动 IP。手机改连家里 WiFi，打开这个地址开关灯。
3. 重新配网：开机 3 秒内再按一次 Reset，或网页里点「更换 WiFi」。

## 烧录和测试

插上板子：

```bash
./upload.sh
```

没板子时，在电脑上跑配网和开关流程：

```bash
./test/run.sh
```

改页面编辑 `web/` 下的 HTML。`upload.sh` 会先把它们嵌进固件。
