# 演示介绍

这个环节用一盏 12V 灯，说明智能控制和普通开关有什么不一样。

普通开关要人走到灯旁边，手去扳那路电。这里人不碰灯也能开：手机点一下，板子收到以后改一个引脚的电平，继电器跟着吸合或松开，灯那边的 12V 才通或断。灯用的电还是 12V 电源给的，WiFi 并不供电。

板子是 Arduino Uno R4 WiFi，程序跑在上面，上网靠板载的 2.4GHz WiFi。手机打开的是板子自己提供的网页，点按钮相当于发一条 HTTP 请求，没有单独做 App，也没有接到云上。GPIO 带不动灯，中间加了一颗 5V 继电器，专门切 12V 回路。WiFi 名称和密码记在板子的 EEPROM 里，换网络不用改灯那侧的线。

这套东西能远程通断、命令和强电是分开的，但没有传感器，也不会自己学习，不要理解成人工智能。
